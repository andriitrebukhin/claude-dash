Install Claude Dash

A round desk display for Claude Code: usage limits, live sessions, and Allow / Deny from a touchscreen. Flash it from this page in about two minutes.

  1. Plug in the display

    Connect the Waveshare ESP32-S3-Touch-LCD-2.1 to this computer with a USB-C data cable. Either of its two ports works; the one labelled UART is the smoothest for this page.

  2. Install the firmware

    Click the button, pick the board's port, and confirm. When it finishes, the page asks for your Wi-Fi.

    Your browser can't talk to USB devices. Open this page in Chrome or Edge on a computer.
    This page needs a secure (https) connection to use USB.

    Used the board's USB port and the Wi-Fi step didn't appear? Click the button again and choose Connect to Wi-Fi. The board briefly drops off USB when it restarts.

  3. Install the Mac plugin

    In Claude Code on your Mac:

    /plugin marketplace add andriitrebukhin/claude-dash
/plugin install desk-display@desk-display

    It runs a small bridge in the background (it starts at login) that tells the display what Claude Code is doing.

  4. Pair

    The display finds your Mac on its own and shows a 4-digit code. A page opens on the Mac with the same code; click Approve. Or plug the display into the Mac's USB, and it pairs with no code.

    Several Macs? On each extra Mac, install the plugin and tap Pair <Mac> on the display.

Updates arrive over Wi-Fi: the display offers each new release with an Update button. Source, docs and manual flashing: github.com/andriitrebukhin/claude-dash.
